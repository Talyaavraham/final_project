# מודל השפה שלנו להתרעות (`nlu/`)

הוא הופך משפט שנכתב בצ'אט, כמו "תתריעי לי אם מישהו מרים סכין", לכלל התרעה. **הכול רץ מקומית**: אין קריאה ל-Claude או לשום שירות חיצוני.

## מה המודל מנבא
שלושה מסווגים קטנים (logistic regression) שיושבים מעל מקודד משפטים:

| ראש | ערכים |
|---|---|
| `kind` | `object`, `hold`, `raise_object`, `hands_up`, `person`, `none` (= משהו שאי אפשר לזהות, או שזו לא בקשת התרעה) |
| `object` | סוג האובייקט לגלאי (`knife`, `gun`, `cell phone`…) |
| `hands` | 1 או 2 |

מספרים, כמו "יותר משני אנשים" או "במשך 3 שניות", נקראים בביטוי רגולרי (`alert_rules.parse_people` / `parse_duration`). המודל לא לומד אותם.

**שני מקודדים לבחירה:**
- `hash`, ברירת המחדל: n-grams של אותיות (2-5) ומילים, עם הסרה של תחיליות עבריות (ו/ה/ש/ב/ל/מ/כ/כש). לא צריך הורדה, מתאמן בשניות על CPU, וקובץ המודל שוקל כ-0.4MB. הוא מכיר **אותיות**, לא **משמעות**, ולכן פועל שלא ראה באימון ("שולף", "מגביה") קשה לו.
- `minilm`: מקודד משפטים רב-לשוני (`paraphrase-multilingual-MiniLM-L12-v2`, עברית + אנגלית) שמבין משמעות. דורש `transformers` והורדה חד-פעמית של כ-470MB. **עוד לא נמדד**, כי ההורדה חסומה בסביבה שבה בנינו את זה. כדאי להריץ אצלכן ולהשוות.

**איך השרת משלב** (`alert_rules.understand`): המודל עדיף בזיהוי סוג הבקשה במשפטים חופשיים ובשאלה אם מדובר ביד אחת או בשתיים. מפענח המילים עדיף בזיהוי שם האובייקט. לכן:
- כששניהם מסכימים על הסוג, הסוג נקבע לפי המודל ושם האובייקט לפי מפענח המילים.
- כשמפענח המילים לא מצא כלום, המודל קובע רק אם הוא בטוח (`MODEL_SURE = 0.6`).
- כשהם לא מסכימים, המודל קובע אם הוא בטוח מאוד (`MODEL_OVERRIDE = 0.8`), ואחרת מפענח המילים.

## הרצה
```bash
cd backend
pip install scikit-learn                # רק לאימון. השרת צריך רק numpy
python nlu/make_dataset.py              # המשפטים מהתבניות -> nlu/data/train.jsonl + test_templates.jsonl
python nlu/train.py                     # -> nlu/model.npz
python nlu/evaluate.py                  # מפענח מילים / מודל / משולב, על כל קבצי הבדיקה
python nlu/evaluate.py --errors         # + המשפטים שהמשולב טעה בהם
python nlu/train.py --encoder minilm    # המקודד הרב-לשוני
```
השרת טוען את `nlu/model.npz` בעלייה. אם הקובץ לא קיים, הוא משתמש רק במפענח המילים. ב-`GET /api` השדה `nlu` מראה איזה מודל נטען.

## הדאטה
| קובץ | מה יש בו |
|---|---|
| `data/train.jsonl` | כ-8,500 משפטים מתבניות (`make_dataset.py`), בעברית ובאנגלית |
| `data/test_templates.jsonl` | כ-1,100 משפטים מתבניות, עם עטיפות ומילים **שלא מופיעות באימון** ("תודיעי לי כש…", "מגביה", "brandishes", "סמארטפון") |
| `data/test_handwritten.jsonl` | 60 משפטים חופשיים שלא נוצרו מתבניות. **נכתבו על ידי Claude כנקודת התחלה, ולא על ידי משתמשים אמיתיים** |
| `data/test_people.jsonl` | **ריק: למלא במשפטים שאנשים אמיתיים כתבו.** זו הבדיקה שבאמת חשובה |

פורמט שורה (JSON):
```json
{"text": "תתריעי לי אם מישהו מרים סכין", "kind": "raise_object", "object": "knife", "hands": 0}
```

**איסוף משפטים מאנשים:** מראים לאנשים 2-3 תרחישים ("את רוצה לדעת אם מישהו מוציא סכין במטבח") ומבקשים מהם לכתוב איך היו מבקשים את ההתרעה, במילים שלהם. מתייגים, ושמים חלק ב-`test_people.jsonl` (בדיקה בלבד) וחלק בקובץ אימון נפרד (`--extra`). **אסור שאותו משפט יופיע בשניהם.**
