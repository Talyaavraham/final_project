# Live — התרעה על פעולות בשידור חי

הכיוון של הבראנץ `live-action-alerts`: מחברים מצלמה שמשדרת בזמן אמת, ומקבלים התרעה כשמישהו מבצע **פעולה**, למשל הרמת סכין.
ההתרעה מוגדרת בשפה חופשית ("תתריעי לי אם מישהו מרים סכין").

## שלבים

1. ✅ **תצוגה חיה:** שלד (pose) ואובייקטים (סכין / אקדח) על השידור, `live_view.py` ובממשק
2. אימון מחדש של גלאי הסכין (`security.pt` חלש על סכינים)
3. ✅ **חוק בסיסי** ל"הרמת סכין" + התרעה (`alert_rules.py`)
4. צילום דאטה: הרמות אמיתיות מול פעולות מבלבלות (חיתוך, הרמת טלפון)
5. מודל נלמד על רצפי שלד + אובייקטים, והשוואה לחוק
6. ✅ **הגדרת התרעות בשפה חופשית** בצ'אט (Claude או מפענח מילים → כלל)

## בממשק (Live Stream)

```bash
cd backend
uvicorn main:app --port 8000
```
פותחים **http://localhost:8000**, לוחצים **Live Stream** (או 🔔 Live Alerts בתפריט):

1. **🔄 Find cameras**: הדפדפן מבקש אישור למצלמה ומציג את כל המצלמות שמחוברות למחשב
2. בוחרים מצלמה ולוחצים **▶ Start**
3. כותבים בצ'אט מתי להתריע, בעברית או באנגלית: "תתריעי לי אם מישהו מרים סכין", "מישהו מחזיק טלפון", "יותר משני אנשים בחדר"
4. כשכלל מתקיים: צפצוף, מסגרת אדומה סביב הווידאו, הודעה בצ'אט, וכרטיס עם צילום ברשימת ה-Alerts

**טלפון כמצלמה:** הדפדפן רואה רק מצלמות שמערכת ההפעלה מכירה כמצלמת רשת. צריך לחבר את הטלפון כמצלמת רשת
(למשל Phone Link ב-Windows 11 עם אנדרואיד, או אפליקציה כמו DroidCam / Iriun / Camo), ואז ללחוץ שוב 🔄.

**איך זה עובד:** הדפדפן שולח פריים אחד (JPEG, ברוחב 640) ב-WebSocket `/live/ws` ומחכה לתשובה לפני שהוא שולח את הבא,
כך שהשרת תמיד עובד על הפריים הכי חדש. השרת (`live_engine.py`) מריץ pose + גלאים ומחזיר אנשים, אובייקטים והתרעות.
הכללים (`alert_rules.py`) נוצרים מהמשפט ב-`POST /live/rules`: Claude כשיש `ANTHROPIC_API_KEY`, אחרת מפענח מילים.

| סוג כלל | מתי מתריע |
|---|---|
| `object` | אובייקט בפריים ("יש אקדח") |
| `hold` | פרק יד על האובייקט ("מישהו מחזיק טלפון") |
| `raise_object` | פרק היד שהחזיק את האובייקט עולה מעל הכתף ("מישהו מרים סכין") |
| `hands_up` | שתי הידיים מעל הכתפיים |
| `person` | לפחות N אנשים ("יותר משני אנשים") |

התנאי צריך להחזיק `duration` שניות (פערים קצרים עד 0.7 שנ' מגושרים, כי הגלאי מהבהב על סכינים),
ויד שנגעה באובייקט "מחזיקה" אותו עוד 1.5 שנ', כך שסכין שנעלמת בטשטוש התנועה עדיין נספרת. כל כלל מתריע לכל היותר פעם ב-5 שנ'.
משהו שעוד לא נתמך ("מישהו נופל", "מכות") מקבל "לא הבנתי" ולא כלל שגוי.

| משתנה | ברירת מחדל | |
|---|---|---|
| `LIVE_POSE` | `yolov8n-pose.pt` | מודל השלד |
| `LIVE_DET` | `yolov8n.pt` | גלאי (COCO, כולל `knife`) |
| `LIVE_EXTRA` | `security.pt` אם קיים | גלאים נוספים (gun / knife / fire / smoke) |
| `LIVE_CONF` / `LIVE_IMGSZ` / `LIVE_DEVICE` | `0.25` / `640` / auto | |

בדיקות: `pytest tests/test_alert_rules.py`

## live_view.py

לכל פריים: מודל pose (`yolov8n-pose.pt`, 17 נקודות לכל אדם, עם מעקב ByteTrack) וגלאי אובייקטים
(`yolov8n.pt`, שיש בו כבר מחלקת `knife` של COCO, ואופציונלית `security.pt`).
על המסך: שלד, מספר מעקב לכל אדם, מסגרות אדומות לאובייקטים, ופרקי הידיים בעיגול גדול. העיגול צהוב כשהיד נמצאת על אובייקט
(רק לבדיקה ויזואלית, זו לא התרעה). בפינה: fps ו-latency.

```bash
cd backend
python live/live_view.py                                     # מצלמת רשת 0
python live/live_view.py --source rtsp://user:pass@IP/stream  # מצלמת IP
python live/live_view.py --extra security.pt                 # + גלאי אקדח / סכין
python live/live_view.py --source clip.mp4 --save out.mp4 --log out.jsonl --no-show
```

| דגל | |
|---|---|
| `--source` | אינדקס מצלמה, כתובת RTSP/HTTP או קובץ וידאו |
| `--pose` / `--det` / `--extra` | המודלים (`--det ''` = בלי גלאי) |
| `--objects` | אילו מחלקות להציג, ברירת מחדל `knife,gun` |
| `--device` | `0` ל-GPU, `cpu` |
| `--save` | שמירת השידור המסומן ל-mp4 |
| `--log` | JSONL: לכל פריים, נקודות השלד של כל אדם וכל מסגרות האובייקטים. זה חומר הגלם לשלבים 3–5 |
| `--no-show` | בלי חלון (שרת / Colab) |

בשידור חי נשמר רק הפריים האחרון: אם המודלים איטיים מהמצלמה, פריימים ישנים נזרקים, כדי שהתצוגה לא תיגרר אחורה.
קובץ וידאו נקרא פריים אחרי פריים, בלי לזרוק כלום.

**מהירות:** על CPU (בלי GPU) נמדדו 2.5–4 fps עם שני המודלים הקטנים. לזמן אמת צריך GPU.
